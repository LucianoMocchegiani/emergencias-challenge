### Paso 2: Instalar y configurar TypeORM con SQLite

**Descripción:**
Añadir las dependencias de TypeORM y el driver de SQLite. Configurar el módulo TypeORM en `AppModule` con la ruta del archivo SQLite (variable de entorno `DATABASE_PATH` o valor por defecto, por ejemplo `./data/contacts.db`). Crear el directorio de datos si no existe y asegurar que SQLite cree el archivo .db si no existe.

**Archivos a modificar/crear:**
- `package.json` (dependencias)
- `src/app.module.ts` (TypeOrmModule.forRoot)
- `.env.example` con `DATABASE_PATH` y `PORT` (opcional)

**Detalles de implementación:**
```typescript
// app.module.ts - ejemplo
TypeOrmModule.forRoot({
  type: 'sqlite',
  database: process.env.DATABASE_PATH || './data/contacts.db',
  entities: [__dirname + '/**/*.entity{.ts,.js}'],
  synchronize: true, // en desarrollo; en producción usar migraciones
  logging: process.env.NODE_ENV === 'development',
}),
```

**Notas:**
- Usar `synchronize: true` solo en desarrollo para que TypeORM cree/actualice tablas desde entidades; en producción se usarían migraciones.
- Añadir `@nestjs/config` (ConfigModule) si se usan variables de entorno desde `.env`.

**Recursos útiles:**
- [TypeORM - SQLite](https://typeorm.io/#/connection-options/sqlite-connection-options)

## Consideraciones Técnicas

### Performance
- Índices en claves foráneas (personId, phoneTypeId) y en columnas de búsqueda (email, activityType).
- TypeORM con SQLite es adecuado para desarrollo y cargas moderadas.

### Seguridad
- Consultas parametrizadas (TypeORM por defecto).
- No exponer rutas de archivo de BD en respuestas; usar variables de entorno para rutas.

### Casos Edge
- Ruta del archivo SQLite: variable de entorno o path por defecto.
- Creación del archivo .db si no existe (comportamiento estándar del driver).
- activityType solo: 'call' | 'meeting' | 'email' (enum + validación).

### Compatibilidad
- Mantener schema alineado con docs/objetivo.md para no bloquear AC-003, AC-004, AC-005.

## Patrones de Código a Usar

- **NestJS:** Módulo raíz en `app.module.ts`, entidades en carpeta `database/entities/` o por dominio.
- **TypeORM:** Entidades con decoradores `@Entity()`, `@PrimaryGeneratedColumn()`, `@Column()`, `@ManyToOne()`, `@OneToMany()`.
- **SQLite:** Tipo `sqlite` en TypeORM; tipos de columna compatibles (TEXT, INTEGER, etc.).
