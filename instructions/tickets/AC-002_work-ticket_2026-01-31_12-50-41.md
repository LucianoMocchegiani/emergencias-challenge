## Descripción

### Problema/Requerimiento

Crear el proyecto NestJS desde cero con TypeScript, configurar SQLite como base de datos y definir el schema con las tablas Person, Phone, PhoneType, Address y ContactActivities según docs/objetivo.md. Incluye bootstrap de la aplicación, módulo de base de datos y creación/migración del schema.

### Comportamiento Actual

- No existe aún código NestJS ni base de datos SQLite.

### Comportamiento Esperado

- Proyecto NestJS inicializable (npm run start:dev).
- Conexión a SQLite configurada (TypeORM, Prisma o better-sqlite3).
- Schema creado con tablas: Person (id, firstName, lastName, dateOfBirth, email), Phone (id, number, personId, phoneTypeId), PhoneType (id, typeName), Address (id, personId, locality, street, number, notes), ContactActivities (id, personId, activityType, activityDate, description).
- activityType solo permite 'call' | 'meeting' | 'email'.
